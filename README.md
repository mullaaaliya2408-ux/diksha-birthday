# 🎀 Bestie Birthday — Interactive Birthday Story

A cute pastel/kawaii birthday microsite built with React + Vite + Framer Motion + canvas-confetti.

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Personalize

Edit only:

`src/data/birthdayData.js`

Add your photos to:

`public/images/`

Expected names:
`memory1.jpg` ... `memory25.jpg`, plus `m26.jpg` ... `m32.jpg`
`final.jpg`

Optional music:
`public/music/birthday.mp3`

The birthday gate accepts:
- 7th Oct
- 7 Oct
- 07/10
- 7/10
- 0710

## Experience

1. Birthday gate
2. Celebration + cats + confetti
3. Tap-to-cut cake
4. Interactive scrapbook
5. Bonus memories reveal (m26–m32)
6. Heartfelt letter
6. Final birthday screen

No backend or API key is required.
